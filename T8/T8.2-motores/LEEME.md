# T8.2 · Motores para el desarrollo de videojuegos

## Contenido

- `T8.2-Motores-para-Videojuegos.pptx`: presentación de 28 diapositivas.
- `T8-2_content/`: imágenes, código y recursos usados en la presentación.
  - `mover_unity.cs`: script de ejemplo para mover un objeto en Unity.
  - `codigo_mover_unity.png`: imagen del código usada en la diapositiva 23.
  - `img/`: capturas del editor de Unity, del editor de Godot, una escena de Unreal y una sesión de VR.
  - `logos/`: logotipos de Unity, Godot, Unreal y Phaser.
  - `template/`: fondos y elementos de pixel art del template del curso.
  - `fonts/`: tipografía Neuromax y su licencia.
- `creditos.md`: fuentes, licencias y enlaces.

## Tipografía

La presentación usa Neuromax (Regular y SemiBold). Para verla como está diseñada, instala los archivos de `T8-2_content/fonts/` en tu sistema.
Si no está instalada, PowerPoint puede sustituirla por otra fuente y cambiar los saltos de línea.

## Código

El código está en `T8-2_content/mover_unity.cs`, con indentación de 4 espacios, sin comentarios y con líneas cortas.
En la diapositiva 23 aparece como imagen para que se lea bien en proyección. Las notas de esa diapositiva contienen el mismo código con espacios, listo para copiar y pegar.

El script mueve un objeto con las teclas de dirección o WASD. Es un ejemplo mínimo de `MonoBehaviour`, `Update`, `Input.GetAxis` y `Time.deltaTime`.

## Notas

Todas las diapositivas tienen notas para el presentador. La diapositiva 23 incluye el código completo en las notas.
Los datos de versiones, precios y licencias son de octubre de 2026. Las licencias cambian: revisa siempre la página oficial antes de empezar un proyecto.
