# T8.7.1 · Controles 2D estilo Mario

Presentación `../T8.7.1-Controles-2D-Mario.pptx` (34 diapositivas: portada, 3 secciones, 29 de contenido y cierre).
Explica el paso de `S5_CubeMove` (Translate) a `S5_VelmaWalk_2D` (velocidades vx/vy, aceleración, salto variable y gravedad propia).

- `img/`: capturas de Unity, en el orden numerado en que se tomaron.
- `codigo/`: scripts, imágenes de código, `convertir_unidades.py` (SMB3 → Unity) y `simulacion_control.py` (réplica en Python de Update()).
- `snippets.py`: fragmentos que se ven en las diapositivas y se copian en las notas.
- Regenerar: `python3 make_code_images.py && python3 make_figures.py && python3 build_deck.py`.

Fuente de las velocidades de SMB3: https://tasvideos.org/GameResources/NES/SuperMarioBros3
